# Apeiron-Deck
Apeiron Deck is a handheld deck for pc and gaming


## Lattepanda 3 Delta 864 Pins:
**Leonardo Pins:**
- D0: X (NOT Connected)
- D1: X (NOT Connected)
- D2: A Button
- D3: B Button
- D4: X Button
- D5: Y Button
- D6: Right Trigger Button (Front)
- D7: Down Arrow Button
- D8: Right Arrow Button
- D9: Left Arrow Button
- D10: Up Arrow Button
- D11: Left Trigger Button (Front)
- D12: Left Trigger (Back)
- D13: Right Trigger (Back)
- A0: Battery Input
- A1: Right Joystick Ry
- A2: Right Joystick Rx
- A3: Left  Joystick Rx
- A4: Left  Joystick Ry
- A5: Left Joystick Button, -> 10k ohm -> Right Joystick Button

**Audio Pins:**
- SPL-: 4 ohm 2 W Left Speaker -
- SPL+: 4 ohm 2 W Left Speaker +
- SPR-: 4 ohm 2 W Right Speaker -
- SPR+: 4 ohm 2 W Right Speaker +

**USB Pins:**
- 5V: Screen USB Vin
- D+: Screen USB D+
- D-: Screen USB D-
- GND: Screen USB GND
